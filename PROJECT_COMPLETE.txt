🚀 GETTING STARTED (5 Minutes)
─────────────────────────────────────────────────────────────────────────────

STEP 1: VIEW THE WEBSITE
  • Open: index.html
  • Drag into browser OR right-click → Open with → Browser
  • You'll see the complete, responsive website

STEP 2: CUSTOMIZE BRAND COLOR
  • Edit: styles/main.css (line ~20)
  • Find: --color-primary: #ff3333;
  • Change to: --color-primary: #your-color;
  • All components automatically update!

STEP 3: ADD YOUR PRODUCTS
  • Edit: index.html
  • Find: <article class="product-card">
  • Copy the product card HTML
  • Paste and modify with your product data
  • See QUICK_START.md for template

STEP 4: ADD PRODUCT IMAGES
  • Create: images/ folder
  • Add your product images
  • Update src paths in HTML

STEP 5: DEPLOY TO WEB
  • Upload entire ironzone/ folder to hosting
  • Test on mobile, tablet, desktop
  • Done! Your website is live! 🎉


🔧 HOW TO CUSTOMIZE
─────────────────────────────────────────────────────────────────────────────

CHANGE BRAND COLOR:
  Edit: styles/main.css
  Change: --color-primary: #ff3333;
  Result: All components automatically update!

CHANGE GRID COLUMNS:
  Edit: styles/responsive.css
  Modify: grid-template-columns: repeat(3, 1fr);
  To: grid-template-columns: repeat(2, 1fr);

ADD NEW SPACING:
  Edit: styles/main.css
  Add: --spacing-3xl: 64px;
  Use: padding: var(--spacing-3xl) 0;

CHANGE FONT SIZE:
  Edit: styles/main.css
  Change: --font-size-base: 14px;
  To: --font-size-base: 16px;

ADD NEW SECTION:
  1. Create new CSS file in styles/
  2. Add HTML in index.html
  3. Link CSS in <head>
  4. Add responsive rules in responsive.css
