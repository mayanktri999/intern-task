## 📱 Responsive Design

### Mobile-First Approach
- Base styles optimized for 320px+
- Progressive enhancement for larger screens
- No horizontal scrolling
- Touch-friendly (44x44px minimum buttons)

### 5 Responsive Breakpoints
```
Mobile:        320px - 639px   (2 col products)
Tablet:        640px - 767px   (2 col products)
Medium:        768px - 1023px  (2 col products)
Large:         1024px - 1199px (3 col products)
XL:            1200px+         (4 col products)
```

## 🎯 How to Customize

### Change Brand Color
```css
/* styles/main.css line 20 */
--color-primary: #your-color;
```

### Change Grid Columns
```css
/* styles/responsive.css */
@media (min-width: 1024px) {
    .products__grid {
        grid-template-columns: repeat(2, 1fr);  /* 2 instead of 3 */
    }
}
```

### Add Spacing Variable
```css
/* styles/main.css */
--spacing-3xl: 64px;

/* Use anywhere */
.section {
    padding: var(--spacing-3xl) 0;
}
```

### Change Font Size
```css
/* styles/main.css */
--font-size-base: 16px;  /* increased from 14px */
```
